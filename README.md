# 🖼️ 照片分类工具 v10.0

基于感知哈希 + 余弦相似度的智能照片分类工具，支持类别感知分类和实时扫描进度。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 🔍 **智能去重** | 感知哈希 + 余弦相似度，找出相似/重复照片 |
| 🏷️ **类别感知** | 8 大类别：人物、建筑、车辆、物件、图表、文档、食物、其他 |
| 📊 **实时进度** | 扫描过程实时显示进度条 |
| 🎨 **Web 界面** | 无需安装，浏览器直接操作 |
| 📁 **文件夹浏览** | 弹窗选择本地文件夹 |
| 🗑️ **批量删除** | 分组展示，勾选后一键删除 |
| ⚡ **本地运行** | 数据不出本机，隐私安全 |

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动服务

```bash
python3 server.py
```

服务默认运行在 `http://127.0.0.1:5001`

### 3. 使用

打开浏览器访问 `http://127.0.0.1:5001`，输入照片文件夹路径，设置相似度阈值，点击"开始扫描"。

## 🔧 技术原理

### 相似度检测流程

1. **感知哈希（pHash）** — 生成 64-bit 图像指纹
2. **余弦相似度** — 比对哈希向量的夹角
3. **类别感知** — 根据图像特征自动归类到 8 大类别
4. **阈值过滤** — 自定义相似度阈值（50%-95%）

### 分类类别

| 类别 | 图标 | 说明 |
|------|------|------|
| 人物 | 👤 | 含人脸或人物主体的照片 |
| 建筑 | 🏢 | 建筑物、场景照片 |
| 车辆 | 🚗 | 汽车、交通工具 |
| 物件 | 📦 | 商品、物品、标签 |
| 图表 | 📊 | 数据图表、统计图 |
| 文档 | 📄 | 文档截图、文字页面 |
| 食物 | 🍜 | 美食、餐点 |
| 其他 | 📷 | 未分类照片 |

## ⚙️ 配置

### 相似度阈值

- **50% 宽松** — 找出风格类似的照片
- **70% 推荐** — 平衡精度与召回（默认）
- **90% 严格** — 仅找出几乎完全相同的照片

### 修改端口

编辑 `server.py` 顶部：

```python
PORT = 5001  # 改为需要的端口
```

| `/upload` | POST | 上传照片 |
| `/delete` | POST | 删除选中照片 |

| `/browse` | GET | 浏览文件夹 |
